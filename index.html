📖 Cú pháp & Ý nghĩa của câu lệnh git clone

Cú pháp chuẩn: git clone <repository_url> [tên_thư_mục_mới]
🎯

Ý nghĩa cốt lõi

git clone dùng để tạo một bản sao cục bộ (local copy) giống hệt 100% với một repository từ xa (remote repository). Lệnh này không chỉ tải về các tệp tin hiện tại mà còn sao chép toàn bộ lịch sử commit, các nhánh (branches) và thẻ (tags).

⚡

Tự động thiết lập Remote

Git tự động thiết lập một remote connection mang tên origin trỏ về URL ban đầu, cho phép người dùng ngay lập tức sử dụng các lệnh git pull và git push mà không cần cấu hình thủ công.

📂

Tạo thư mục & Checkout

Tự động khởi tạo thư mục mới chứa dự án, khởi tạo kho lưu trữ .git bên trong và tự động checkout nhánh mặc định (như main hoặc master) để sẵn sàng làm việc.

🛠️

Tùy chọn nâng cao thường dùng

• git clone <url> my-folder: Đổi tên thư mục khi tải về.
• git clone -b <branch> <url>: Clone trực tiếp một nhánh cụ thể.
• git clone --depth 1 <url>: Clone nông (chỉ lấy commit gần nhất, giúp tải siêu nhanh).

🔍 Phân biệt git clone với các thao tác khác

Lệnh / Thao tác Mục đích Thời điểm sử dụng
git clone Tải trọn vẹn cả dự án + lịch sử từ máy chủ về máy chưa có mã nguồn Bắt đầu tham gia dự án lần đầu tiên
git pull Cập nhật những thay đổi mới nhất từ remote về repo đã có sẵn trên máy Hàng ngày trước khi bắt đầu viết code
git init Khởi tạo một repo Git mới hoàn toàn từ một thư mục trống cục bộ Bắt đầu một dự án mới tinh trên máy cá nhân
Fork (GitHub) Nhân bản repo của người khác vào tài khoản GitHub cá nhân của mình Đóng góp mã nguồn mở (Open Source) hoặc tùy biến riêng
