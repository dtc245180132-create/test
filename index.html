Luyện tập nhúng CSS vào trang web

Phần 1: Tiêu đề sử dụng Inline Style

Đoạn văn này được thay đổi màu sắc trực tiếp thông qua thuộc tính style nội tuyến (inline-style).

Phần 2: Tiêu đề sử dụng Internal Style

Đoạn văn này được thay đổi màu sắc thông qua thẻ <style> nội bộ nằm trong phần <head> (internal-style).

Phần 3: Tiêu đề sử dụng External Style

Đoạn văn này được thay đổi màu sắc thông qua tệp tin CSS độc lập bên ngoài style.css (external-style).
