Thanh điều hướng Responsive Navbar

Thanh điều hướng được xây dựng bằng HTML, CSS Flexbox, Media Queries và JavaScript.
• Trên Desktop (> 768px): Hiển thị đầy đủ menu ngang.
• Trên Mobile (≤ 768px): Tự động ẩn menu ngang và hiển thị biểu tượng hamburger (☰). Khi click vào biểu tượng ☰ sẽ mở hoặc đóng danh sách menu dạng dropdown.
